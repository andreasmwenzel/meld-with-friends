# Security

Please don't open a public issue for a security problem. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/andreasmwenzel/meld-with-friends/security/advisories/new).
You'll get a reply as soon as it has been looked at, and credit in the fix if you'd like it.

In scope: the app at its production domain, this repository's code, and anything that would let a
player see another player's hidden cards or act for another seat.
